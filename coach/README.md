# coach/

The coaching loop. The app logs; this folder is where the log gets read.

```
coach/
  DECISIONS.md      dated log of every program decision and the data it rested on  (committed)
  PHYSIQUE.md       the weekly posing and tape protocol                             (committed)
  README.md         this file                                                       (committed)
  data/backups/     backup JSON files exported from the phone                       (gitignored)
  data/physique/    posing clips, extracted frames and tape measurements            (gitignored)
  reports/          Markdown reviews generated by tools/review.mjs                  (gitignored)
```

The repo is public. Training data, bodyweight and GPS tracks never go in it —
`data/` and `reports/` are gitignored and stay on this machine.

## The loop

1. On the phone: **Settings → Export backup** → AirDrop the JSON to the Mac and
   drop it in `coach/data/backups/`.
2. In Claude Code, in this project: `/review`. That runs `tools/review.mjs` on
   the newest backup, reads the report against `research/BRIEF.md`,
   `coach/DECISIONS.md` and the rules in `research/SYNTHESIS.md`, and gives an
   assessment with next steps.
3. Anything that changes the program goes through the research reviewer
   (`.claude/agents/program-reviewer.md`) before it lands in
   `src/program/`, and gets a dated entry in `DECISIONS.md`.

`node tools/review.mjs coach/data/backups/<file>.json` works on its own too;
`--since YYYY-MM-DD` narrows the period, `--stdout` prints instead of writing,
`--help` prints the usage. Records the backup format rejects are named in the
report and on stderr rather than quietly left out.

## The physique loop

Weekly, alongside the training review — protocol in `coach/PHYSIQUE.md`:

1. Twenty seconds of video, four poses, same spot and light every week; arm and
   calf measurements into `coach/data/physique/measurements.md`.
2. `node tools/physique.mjs coach/data/physique/<date>.mov` (needs
   `brew install ffmpeg`) → frames plus a numbered contact sheet.
3. The `physique-analyst` agent reads them against the latest review report and
   writes `research/physique-audit.md` for the specialists.

Its first run is methodology, not assessment: it establishes what can honestly
be measured and writes `research/physique-metrics.md`. Expect "the frames cannot
support that" as a frequent and correct answer — a camera measures width, and
width is confounded by scapular position.

## What the report is

Deterministic. Every number is computed by the same `src/core/` modules the
app runs — adherence, the block reference after every heavy session, accessory
stalls per gym and station, every run against the spike and weekly rails,
CR10 and talk test by weekday, bodyweight drift, the reactive-deload
conditions — and the rules in the synthesis are applied to them mechanically
("Rules that fired"). The judgement is the reader's; the report exists so it
never depends on anyone remembering a number.
