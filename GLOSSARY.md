# Training App

A single-user training program for strength, hypertrophy and a 10K, and the log of everything performed against it.

## Language

### Plan and performance

**Day**:
One of the program's templates, such as Upper Push or the long run: what a session of that kind prescribes.
_Avoid_: Workout, template, routine

**Session**:
One occurrence of a day that has a record, because it was started, completed or skipped.
_Avoid_: Workout, training

**Planned day**:
A day the calendar projects onto a future date. It becomes a session only when started, and it moves if earlier sessions slip.
_Avoid_: Planned workout, upcoming session, scheduled session

**Template week**:
The program's fixed layout of days onto weekdays, which is the target a week is measured against.
_Avoid_: Schedule, plan

**Bonus day**:
An optional day outside the template week. Its sets count as performed, so it can pay back a shortfall, but it is never part of the target.
_Avoid_: Extra session, optional workout

### Attendance

**Skipped session**:
A session closed without training. The program moves past its day, so that day's sets are lost for the cycle.
_Avoid_: Missed session

**Missed day**:
A planned day whose date passed with no session. The day is still owed and is the next one offered, so no particular muscle loses out.
_Avoid_: Skipped day

**Shortfall**:
The direct sets the template week prescribes for a muscle, minus those actually performed, accumulated over weeks.
_Avoid_: Deficit, missed volume, lost sets

### Measurement

**Direct set**:
A completed working set, credited only to the muscle the exercise mainly trains.
_Avoid_: Hard set

**Probe**:
The first working set of a heavy day: a few reps at a set effort, there to measure strength rather than build it.
_Avoid_: Top set

**Block reference**:
The one-rep-max estimate that sets a main lift's back-off loads for the block. It only ever rises.
_Avoid_: Training max

**Estimated 1RM**:
The best probe's one-rep-max estimate within the current block. Unlike the block reference it can fall. For the weighted pull-up it is the belt load at current bodyweight.
_Avoid_: Predicted max, PR

### Running

**Route**:
A path planned on the map and saved for reuse, chosen when a run starts.
_Avoid_: Track, course

**Track**:
The path a run actually recorded by GPS.
_Avoid_: Route
